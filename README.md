# Bug System Tracker

A desktop-based Bug Tracking System developed as a project for the PL2 course.

## About the Project

Bug System Tracker is a Java application designed to manage and track software bugs throughout the testing and development process.

The system provides different roles with different responsibilities:

- **Tester:** Can report bugs and view their reported bugs.
- **Developer:** Can review reported bugs and update their statuses.
- **Admin:** Has full access to the system and can manage all aspects of the application.

The application starts with a **Login Page**, where users authenticate using their username and password. Depending on the user's role, they are redirected to the appropriate part of the system.

Administrators are directed to an **OTB (One-Time Backup)** page before accessing the main dashboard.

## Technologies Used

- **Java**
- **Java Swing** — for the graphical user interface.
- **Text Files** — used for storing and managing application data.

This is my **first actual project developed using Java**. It was created as part of the PL2 course and gave me practical experience in building a complete desktop application, working with Java Swing, handling user roles and authentication, and managing persistent data using files.
